Visualizing and Summarizing Wildfire Damage in California

Sardys Avile-Martinez

2025-04-30

Introduction

Welcome to wildvizR — a lightweight R package that empowers users to explore, summarize, and visualize wildfire data in California. This vignette demonstrates how to use the core functions of the package with a sample dataset included in the package folder.

Let’s walk through it.

Load the Data

The dataset is stored in inst/extdata and accessed with system.file():


wildfire_data <- read.csv(system.file("extdata", "Cleaned_California_Wildfire_Damage.csv", package = "wildvizR"))
wildfire_data <- clean_column_names(wildfire_data)

Summarize Wildfire Damage by Year

Use summarize_wildfire_damage() to get an annual summary of acres burned and total financial loss.


summary <- summarize_wildfire_damage(wildfire_data)
print(summary)
